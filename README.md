
Mental Health Text Classifier

A Machine Learning + NLP project that classifies mental-health-related text into predefined categories using text preprocessing, TF-IDF feature extraction, and a supervised machine learning model. A Streamlit web application provides an interactive interface for real-time predictions.

Disclaimer: This project is for educational purposes only and is not a medical diagnostic tool.

🚀 Features
Text preprocessing and cleaning
TF-IDF-based feature extraction
Machine learning text classification
Model performance evaluation
Real-time text prediction
Interactive Streamlit interface
Saved model and vectorizer using Pickle
🛠️ Tech Stack

Python | Pandas | NumPy | Scikit-learn | NLTK | Matplotlib | Seaborn | Streamlit
